# edliau.github.io

repo for personal website, built using plain HTML5, CSS and vanilla JavaScript (no build step).

- `index.html` – the page
- `css/styles.css` – design tokens (colours, fonts, motion) at the top, then one block per section
- `scripts/` – one small script per feature: typing + sparks, scroll reveals, nav + progress, photo switcher, project accordion, interest band, lights (dark mode), bridge hand dealer, and highlighter mode (try ↑↑↓↓←→←→BA)

`generator.html` (the ya-leh-nus generator) still uses Tailwind from a CDN.
